Website Portofolio Pribadi

Studi kasus pembuatan website statis multi-halaman dengan validasi login JavaScript.

Latar Belakang

Proyek ini dibuat sebagai tugas Ujian Tengah Semester pada mata kuliah pemrograman web. Tujuannya adalah membuat website statis multi-halaman yang menerapkan HTML, CSS, Bootstrap 5, dan JavaScript. Saya memilih tema portofolio pribadi agar sekaligus menjadi identitas digital saya sebagai mahasiswa Pendidikan Teknologi Informasi.

Tujuan Proyek

  • Menerapkan komponen Bootstrap 5 seperti navbar, card, button, form, dan alert.
  • Membuat minimal lima halaman yang saling terhubung melalui navigasi.
  • Menerapkan validasi form login menggunakan JavaScript.
  • Mempublikasikan website secara online melalui GitHub Pages.

Fitur Utama

Desain Responsif
Rapi di HP, tablet, dan desktop.
Validasi Login
Email & password diperiksa.
Filter Kategori
Menyaring daftar proyek.
Menu Mobile
Navbar collapse Bootstrap.

Proses Pengerjaan

Menentukan tema, membuat struktur halaman, memilih skema warna (ungu dan kuning), serta menyusun kerangka navigasi antar halaman.

Menyusun HTML dengan komponen Bootstrap 5: navbar, hero section, card grid, form, dan footer. Ditambah CSS kustom untuk warna brand.

Menambahkan validasi form login, filter proyek, lalu mengunggah proyek ke GitHub dan mengaktifkan GitHub Pages.
